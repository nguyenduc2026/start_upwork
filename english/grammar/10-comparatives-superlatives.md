# Ngữ pháp 10 — So sánh hơn & so sánh nhất

> **Tuần 4** · Giai đoạn 1 · 60 phút, chia 3 ngày × 20 phút
> **Lịch học:** Ngày 1: so sánh hơn · Ngày 2: so sánh nhất · Ngày 3: so sánh, đề xuất giải pháp. Có thể chuyển buổi luyện thêm sang tuần sau.
> **Cần học trước:** [Bài 08](08-articles.md), [Bài 09](09-time-prepositions.md).

**Sau bài này bạn có thể:** so sánh hiệu năng/chi phí của hai phương án, chọn phương án trong một nhóm và trình bày kết luận có phạm vi, số liệu rõ ràng.

# PHẦN 1 — SO SÁNH HƠN (Comparatives)

## 1.1 Khái niệm

So sánh hơn nói một đối tượng có đặc điểm ở mức cao/thấp hơn đối tượng khác. *This query is faster than the old one* so hai truy vấn về tốc độ, không tự khẳng định truy vấn mới tốt hơn ở mọi tiêu chí. Cần nói rõ tiêu chí và điều kiện đo khi báo cáo hiệu năng.

## 1.2 Công thức

| Dạng | Công thức / ví dụ |
|---|---|
| (+), tính từ ngắn | S + be + adjective-er + than + đối tượng. *This query is faster than that one.* |
| (+), tính từ dài | S + be + more + adjective + than + đối tượng. *This design is more flexible than the old one.* |
| (−) | S + be not + dạng so sánh. *It isn't faster than the old one.* |
| (?) | Be + S + dạng so sánh? *Is it faster than the old one?* |
| Wh- | *Which option is cheaper?* / *How much faster is it?* |
| Trả lời ngắn | *Yes, it is. / No, it isn't.* |

I + *am*; he/she/it/số ít + *is*; you/we/they/số nhiều + *are*. Thì quá khứ đổi thành was/were; tương lai dùng *will be*: *It will be more expensive*. Viết tắt *isn't, aren't, wasn't, weren't, won't be* như bài trước. Không chia dạng so sánh theo chủ ngữ.

## 1.3 Quy tắc biến đổi

| Loại | So sánh hơn | Ví dụ |
|---|---|---|
| Một âm tiết | Thêm -er | fast → faster; small → smaller |
| Cuối -e | Thêm -r | safe → safer; large → larger |
| Một âm tiết, cuối phụ âm–nguyên âm–phụ âm | Gấp đôi phụ âm, trừ w/x/y | big → bigger; hot → hotter; new → newer |
| Hai âm tiết, phụ âm + y | y → ier | easy → easier; busy → busier |
| Phần lớn tính từ dài | more + tính từ | more reliable, more expensive, more useful |
| Một số tính từ hai âm tiết | Có hai cách | simpler / more simple; narrower / more narrow |
| Bất quy tắc | Học riêng | good → better; bad → worse; far → farther/further |
| Ít hơn | less + tính từ | less expensive, less complex |

Đếm **âm tiết**, không đếm số chữ. Không mặc định mọi tính từ hai âm tiết đều dùng -er: *useful → more useful*. Với người mới học, ưu tiên *simpler*, *more reliable*, *more useful*. *Farther/further* đều dùng cho khoảng cách; *further* còn dùng nghĩa “thêm nữa”.

Đuôi -er thường /ə/ (Anh–Anh), /ɚ/ (Anh–Mỹ), không thêm một âm /r/ cứng theo cách đọc tiếng Việt. *Than* thường giảm âm /ðən/. *Better* /ˈbetə/ (Anh–Anh), *worse* /wɜːs/ (Anh–Anh).

## 1.4 Cách dùng

**① So hai phương án:** *This server is cheaper than that one.* / *The new API is more reliable than the old API.*

**② So trước và sau:** *The page is faster after the update.* / *The configuration is simpler now.* Đối tượng so có thể được hiểu từ ngữ cảnh, không bắt buộc luôn có than.

**③ Nhấn mức chênh lệch:** *This query is much faster.* / *The new plan is slightly more expensive.* Dùng *much, far, a lot, a little, slightly*; không dùng *very faster*.

## 1.5 Dấu hiệu và lưu ý

*Than*, *before/after*, *compared with*, *much/slightly* thường gợi ý so sánh. *Than* đứng trước đối tượng so: *faster than the old query*. Không viết *more faster* hoặc *more better*.

- *As + tính từ gốc + as* = ngang bằng: *This option is as reliable as that one*. Phủ định: *It isn't as fast as the old version*. Không dùng *as faster as*.
- *Fewer + danh từ đếm được số nhiều*: *fewer errors*. *Less + danh từ không đếm được*: *less time*. *Less expensive* lại là *less + tính từ*, hoàn toàn đúng.
- So cùng loại: *The response time of API A is shorter than that of API B*, hoặc đơn giản *API A responds faster than API B*.

## 1.6 Ví dụ

| Câu | Cách dùng |
|---|---|
| This query is faster than the old query. | ① tốc độ |
| This plan is less expensive than the other plan. | ① chi phí thấp hơn |
| The new flow is easier to understand. | ② trước/sau |
| The tests are more reliable now. | ② trước/sau |
| The new server is slightly more expensive. | ③ mức nhỏ |
| The checkout page is much faster in our staging test. | ③ mức lớn, phạm vi đo |
| The new validation produces fewer errors. | Bổ sung: danh từ đếm được |
| This task takes less time now. | Bổ sung: không đếm được |

## 1.7 Lỗi thường gặp

| ❌ | ✅ | Lý do |
|---|---|---|
| more faster | faster | Không dùng kép more + -er |
| more good | better | Bất quy tắc |
| easyer | easier | Phụ âm + y → ier |
| faster then | faster than | Then = sau đó; than = so sánh |
| very faster | much faster | Trạng từ mức độ phù hợp |
| as faster as | as fast as | As...as dùng dạng gốc |

## 1.8 Bài tập Phần 1

### A. Viết dạng so sánh hơn

1. fast
2. safe
3. big
4. easy
5. reliable
6. good
7. bad
8. expensive

### B. Điền từ/dạng thích hợp

1. This query is ___ (fast) than the old one.
2. The design is ___ (simple) now. (ưu tiên dạng -er)
3. This plan is ___ (expensive) than that plan. (đắt hơn)
4. The patch is much ___ (good).
5. We have ___ errors now. (fewer/less)
6. The task takes ___ time now. (fewer/less)

### C. Sửa lỗi

1. This query is more faster.
2. The design is easyer to use.
3. This server is cheaper then that one.
4. The page is very faster now.
5. It is as faster as the old version.
6. This change is more good.

<details>
<summary>Đáp án Phần 1</summary>

**A.** 1. faster · 2. safer · 3. bigger · 4. easier · 5. more reliable · 6. better · 7. worse · 8. more expensive.

**B.** 1. faster · 2. simpler · 3. more expensive · 4. better · 5. fewer · 6. less.

**C.** 1. **faster** · 2. **easier** · 3. cheaper **than** · 4. **much faster** · 5. as **fast** as · 6. **better**.

</details>

# PHẦN 2 — SO SÁNH NHẤT (Superlatives)

## 2.1 Khái niệm

So sánh nhất chỉ đối tượng có mức cao/thấp nhất trong một nhóm được xét, thường có từ ba thành viên trở lên. *This is the fastest query in our test* giới hạn kết luận trong bài test đó. Không suy ra nó nhanh nhất trong mọi hệ thống hay mọi dữ liệu.

## 2.2 Công thức

| Dạng | Công thức / ví dụ |
|---|---|
| (+), tính từ ngắn | S + be + the + adjective-est + (danh từ) + phạm vi. *This is the fastest query in the test.* |
| (+), tính từ dài | S + be + the most + adjective + (danh từ). *This is the most reliable option.* |
| (−) | *It isn't the cheapest option.* |
| (?) | *Is this the safest option?* |
| Wh- | *Which option is the cheapest?* |
| Trả lời ngắn | *Yes, it is. / No, it isn't.* |

Chia be theo chủ ngữ/thì như Phần 1. Dạng so sánh nhất không đổi theo số: *the fastest server / the fastest servers*. *One of the + so sánh nhất + danh từ số nhiều*: *one of the best options*.

## 2.3 Quy tắc biến đổi và phát âm

| Loại | So sánh nhất | Ví dụ |
|---|---|---|
| Một âm tiết | -est | fast → fastest |
| Cuối -e | -st | safe → safest; large → largest |
| Một âm tiết, cuối phụ âm–nguyên âm–phụ âm | Gấp đôi phụ âm, trừ w/x/y | big → biggest; hot → hottest; new → newest |
| Hai âm tiết, phụ âm + y | -iest | easy → easiest; busy → busiest |
| Phần lớn tính từ dài | most + tính từ | most reliable; most useful |
| Một số hai âm tiết | Có hai cách | simplest / most simple |
| Bất quy tắc | Học riêng | good → best; bad → worst; far → farthest/furthest |
| Thấp nhất | least + tính từ | least expensive; least complex |

Đuôi -est thường /ɪst/: *fastest* /ˈfɑːstɪst/ (Anh–Anh). *Best* /best/ và *worst* /wɜːst/ (Anh–Anh) là dạng riêng. Không viết *most fastest, most best*. *The* thường cần trong cụm danh từ so sánh nhất; xem [Bài 08](08-articles.md).

## 2.4 Cách dùng

**① Chọn mức cao/thấp nhất trong nhóm:** *Option B is the cheapest of the three.* / *This is the most reliable server in our test.*

**② Xếp ưu tiên:** *This is the most urgent bug.* / *The checkout issue is the highest priority.*

**③ Một thành viên của nhóm đứng đầu:** *This is one of the best tools for our workflow.* / *She is one of the most experienced developers on the team.* Không khẳng định chỉ có duy nhất một người/công cụ tốt nhất.

## 2.5 Dấu hiệu và ngoại lệ

*In this test, on the team, of the three, among these options* chỉ phạm vi. Thường dùng *in + nhóm/nơi*: *in the team*; *of + tập được nêu*: *of the three*. *On the team* cũng đúng, đặc biệt Anh–Mỹ.

- Sau sở hữu không thêm the: *our best option*, không phải *our the best option*.
- Khi tính từ đứng sau be và không có danh từ, đôi khi có thể bỏ the: *Which is cheapest?* Trong bài này ưu tiên mẫu đầy đủ dễ dùng: *Which option is the cheapest?*
- Với hai phương án, dùng so sánh hơn là lựa chọn chuẩn, rõ: *Option A is cheaper than B*. So sánh nhất xuất hiện trong giao tiếp về hai đối tượng, nhưng chưa cần lấy đó làm mẫu chính.

## 2.6 Ví dụ

| Câu | Cách dùng |
|---|---|
| This is the cheapest of the three plans. | ① nhóm rõ |
| Query B is the fastest in this test. | ① phạm vi đo |
| This is the least complex option. | ① mức thấp nhất |
| The payment issue is the most urgent bug. | ② ưu tiên |
| This is one of the best tools for our team. | ③ một trong nhóm |
| She's one of the most reliable developers here. | ③ một trong nhóm |
| This is our best option for now. | Sở hữu thay the |
| Which solution is the safest for this release? | ① hỏi lựa chọn |

## 2.7 Lỗi thường gặp

| ❌ | ✅ | Lý do |
|---|---|---|
| the most fastest | the fastest | Không dùng kép |
| the goodest | the best | Bất quy tắc |
| one of the best tool | one of the best tools | One of + nhóm số nhiều |
| our the best option | our best option | Không the sau our |
| the most easy | the easiest | Mẫu ưu tiên với easy |
| This is best option. | This is the best option. | Cụm danh từ cần từ hạn định |

## 2.8 Bài tập Phần 2

### A. Viết dạng so sánh nhất (kèm the)

1. fast
2. safe
3. big
4. easy
5. reliable
6. good
7. bad
8. expensive

### B. Điền dạng đúng

1. This is ___ (cheap) of the three plans.
2. Query B is ___ (fast) in this test.
3. This is one of the best ___ (tool) for our team.
4. She is one of the most reliable ___ (developer) here.
5. This is ___ (urgent) bug in this release.
6. This is our ___ (good) option.

### C. Sửa lỗi

1. This is the most fastest query.
2. It is the goodest option.
3. This is one of the best tool.
4. This is our the best plan.
5. It's the easyest solution.
6. This is safest option in the test.

<details>
<summary>Đáp án Phần 2</summary>

**A.** 1. the fastest · 2. the safest · 3. the biggest · 4. the easiest · 5. the most reliable · 6. the best · 7. the worst · 8. the most expensive.

**B.** 1. the cheapest · 2. the fastest · 3. tools · 4. developers · 5. the most urgent · 6. best.

**C.** 1. **the fastest** · 2. **the best** · 3. best **tools** · 4. **our best plan** · 5. **the easiest** · 6. **the safest option**.

</details>

# PHẦN 3 — SO SÁNH VÀ VẬN DỤNG

## 3.1 Bảng so sánh

| Tiêu chí | So sánh hơn | So sánh nhất |
|---|---|---|
| Bản chất | So với đối tượng khác | Đứng đầu/cuối trong nhóm |
| Công thức | -er / more... + than | the -est / the most... + phạm vi |
| Phủ định/câu hỏi | isn't faster / Is it faster? | isn't the fastest / Is it the fastest? |
| Cách dùng | Đối chiếu hai phương án, trước/sau | Chọn trong nhóm, xếp ưu tiên |
| Dấu hiệu | than, much, slightly | of the three, in this test |
| Đặc biệt | better, worse; as...as dùng dạng gốc | best, worst; our best; one of the best options |

## 3.2 Cặp câu đối chiếu

| So sánh hơn | So sánh nhất | Khác nhau ở đâu |
|---|---|---|
| A is cheaper than B. | A is the cheapest of the three. | So với B ↔ toàn nhóm ba |
| This query is faster than the old one. | This is the fastest query in our test. | Một đối thủ ↔ nhóm đo |
| This bug is more urgent than the UI bug. | This is the most urgent bug in this release. | Hai bug ↔ toàn release |

## 3.3 Mẹo chọn nhanh

1. Đang so với một đối tượng hay so trước/sau? → so sánh hơn.
2. Đang chọn mức cao/thấp nhất trong nhóm? → so sánh nhất, nêu nhóm.
3. Tính từ thuộc dạng ngắn/dài/bất quy tắc nào? → chọn dạng.
4. Kiểm tra *than*, *the*, *one of + số nhiều* và bằng chứng cho kết luận.

> *I compared three hosting plans. Plan B is cheaper than Plan C, but Plan A is the cheapest of the three. In our test, Plan B was more stable than Plan A. I think Plan B is the best option for this project because reliability is our main priority.*

## 3.4 Bài tập tổng hợp

### A. Chọn đúng

1. This query is (faster / fastest) than the old one.
2. This is (the cheapest / cheaper) of the three plans.
3. The new flow is (easier / more easier) to use.
4. We have (fewer / less) bugs now.
5. It takes (less / fewer) time.
6. This is one of the best (tools / tool).
7. This is our (best / the best) option.
8. It isn't as (fast / faster) as the old query.
9. If the tests (pass / will pass), we'll deploy. (ôn Bài 07)
10. I'll send the report (by / until) noon. (hạn, ôn Bài 09)

### B. Sửa lỗi

1. This plan is more cheaper.
2. This is the most safest option.
3. The new API is gooder.
4. This is one of the best solution.
5. This query is faster then the old query.
6. It is as cheaper as that plan.

### C. Viết đề xuất

Ba gói hosting đã được đo trong cùng bài test: A — $10/tháng, 300 ms, tỷ lệ request thành công 99%; B — $20/tháng, 180 ms, 99.9%; C — $30/tháng, 160 ms, 99.9%. Viết 6–8 câu, có hai so sánh hơn, hai so sánh nhất và một đề xuất với should. Nêu rõ số liệu thuộc bài test; “tốt nhất” phải gắn với tiêu chí. B và C có cùng tỷ lệ thành công nên không tự khẳng định chỉ B ổn định nhất.

<details>
<summary>Đáp án và gợi ý Phần 3</summary>

**A.** 1. faster · 2. the cheapest · 3. easier · 4. fewer · 5. less · 6. tools · 7. best · 8. fast · 9. pass · 10. by.

**B.** 1. **cheaper** · 2. **the safest** · 3. **better** · 4. best **solutions** · 5. faster **than** · 6. as **cheap** as.

**C. Mẫu:** I compared three hosting plans in the same test. Plan A is the cheapest at $10 per month. Plan B is cheaper than Plan C. Plan B is also faster than Plan A in this test. Plan C is the fastest at 160 ms. Plans B and C had the same success rate of 99.9%. We should choose Plan B if cost and reliability are our main priorities. It offers a lower price than C with the same measured success rate.

</details>
