# PHẦN 1 — CÂU ĐIỀU KIỆN LOẠI 1 (First Conditional)

## 1.1 Khái niệm

Câu điều kiện loại 1 nêu một tình huống tương lai mà người nói xem là có thể xảy ra, cùng kết quả phụ thuộc vào nó. Câu có hai mệnh đề: điều kiện với *if* và kết quả. *If you send the design today, I'll review it tonight* chỉ hứa review tối nay **khi** nhận thiết kế hôm nay.

## 1.2 Công thức

| Thành phần | (+) | (−) | (?) |
|---|---|---|---|
| Mệnh đề if, động từ thường | If S + V(s/es) | If S + don't/doesn't + V | Không đảo trợ động từ trong mệnh đề if |
| Mệnh đề if, be | If S + am/is/are | If S + am not/isn't/aren't | Giữ thứ tự S + be |
| Kết quả với will | S + will + V | S + won't + V | Will + S + V + if ...? |

*I/you/we/they + send*; *he/she/it + sends*. *If the tests pass, we'll deploy.* Nếu điều kiện đứng trước, đặt dấu phẩy; nếu đứng sau thường không cần: *We'll deploy if the tests pass.*

- *Will you deploy if the tests pass? — Yes, I will. / No, I won't.*
- Wh-: *What will you do if the deployment fails?*
- Phủ định có thể ở một hoặc hai vế: *If you don't approve the design, we won't start development.*
- Viết tắt: *I'll, we'll, won't, don't, doesn't, isn't, aren't* theo các bài trước.

## 1.3 Biến đổi và phát âm

Không có dạng “động từ điều kiện” riêng. Chia hiện tại đơn trong vế if, dùng nguyên mẫu sau modal trong vế kết quả. Ôn các dạng dễ sai: *pass → passes* (đuôi /ɪz/), *fail → fails* (/z/), *work → works* (/s/), *try → tries*, *have → has*. Không thêm -s sau *will/can*.

## 1.4 Cách dùng

**① Điều kiện để làm việc:** *If you approve the design, I'll start development.* / *If the tests pass, we'll deploy the patch.*

**② Rủi ro và phương án ứng phó:** *If the deployment fails, we'll roll back.* / *If the payment fails, I'll check the logs.*

**③ Kết quả về khả năng hoặc lời khuyên:** *If you share the logs, I can investigate.* / *If the server is slow, you should check the metrics.* Vế kết quả có thể dùng *can, could, should* theo nghĩa cần nói, không bắt buộc chỉ có will.

**④ Hướng dẫn:** *If you see this error, send me a screenshot.* / *If the tests fail, don't deploy.* Vế kết quả là mệnh lệnh, dùng V hoặc *don't + V*.

## 1.5 Dấu hiệu và vị trí

*If* = nếu; *unless* = nếu không/trừ khi. *Tomorrow, tonight, by Friday* có thể làm rõ tương lai, thường ở cuối mệnh đề liên quan. *If* không tự chứng minh là loại 1: cần nhìn ý nghĩa tương lai của cả câu.

- *Unless you approve the design, I won't start.* = *If you don't approve the design, I won't start.*
- Không thêm một phủ định thừa sau unless khi muốn nghĩa trên: *Unless you don't approve...* đổi nghĩa.

## 1.6 Lưu ý và ngoại lệ

- Vế if chỉ điều kiện tương lai thông thường dùng hiện tại đơn: *If it fails...*, không phải *If it will fail...* Có các cách dùng will diễn đạt sự sẵn lòng, nhưng không cần dùng ở trình độ bài này.
- *When* = khi, xem sự kiện là dự kiến sẽ xảy ra: *When you receive the file, let me know*. *If you receive it...* để ngỏ có nhận hay không.
- Không dùng *would* trong mẫu loại 1 cơ bản: *If you send it, I'll review it*. *Would* trong điều kiện giả định thuộc bài khác.
- Một câu đúng ngữ pháp vẫn có thể là lời hứa không thực tế. Khi chưa ước lượng, dùng *If you send the logs, I'll investigate and give you an estimate*.

## 1.7 Ví dụ

| Câu | Cách dùng |
|---|---|
| If you send the mockup, I'll review it. | ① điều kiện |
| We won't deploy if the tests fail. | ① phủ định kết quả |
| If the backup fails, we'll retry it. | ② phương án |
| If the issue returns, I'll investigate. | ② ứng phó |
| If you give me access, I can check the logs. | ③ khả năng |
| If the server is overloaded, we should reduce the load. | ③ lời khuyên |
| If you see an error, take a screenshot. | ④ hướng dẫn |
| Unless the client approves, we won't start. | ① unless |

## 1.8 Lỗi thường gặp

| ❌ | ✅ | Lý do |
|---|---|---|
| If it will fail, I'll retry. | If it fails, I'll retry. | Hiện tại trong vế if |
| If she approve, we'll start. | If she approves, we'll start. | She → -s |
| If tests pass, we will deploys. | If tests pass, we will deploy. | Will + V |
| If you send it, I would review it. | If you send it, I'll review it. | Mẫu loại 1 |
| What you will do if it fails? | What will you do if it fails? | Đảo will ở câu hỏi chính |
| If it doesn't works, call me. | If it doesn't work, call me. | Doesn't + V |

## 1.9 Bài tập Phần 1

### A. Chia động từ

1. If the tests ___ (pass), we ___ (deploy).
2. If she ___ (approve), I ___ (start).
3. If the API ___ (not / respond), I ___ (check) the logs.
4. If you ___ (not / send) the file, we ___ (not / finish) the review tonight.
5. If the server ___ (be) slow, we ___ (add) caching.
6. If you ___ (see) an error, ___ (send) a screenshot. (mệnh lệnh)
7. If the tests ___ (fail), ___ (not / deploy). (mệnh lệnh)
8. If you ___ (share) the logs, I can ___ (investigate).

### B. Viết lại theo yêu cầu

1. We will deploy if the tests pass. → bắt đầu bằng If
2. If you send it today, I'll review it tonight. → đặt vế if sau
3. If you don't approve the design, we won't start. → dùng Unless
4. You will roll back if it fails. → Yes/No
5. You will **check the logs** if it fails. → hỏi What
6. Will you help if I send the logs? → Yes với I

### C. Sửa lỗi

1. If the API will fail, I'll retry.
2. If he agree, we'll start.
3. If it doesn't works, call me.
4. We will to deploy if it passes.
5. What you will do if it fails?
6. If you send it, I would check it tonight. (dùng loại 1)

<details>
<summary>Đáp án Phần 1</summary>

**A.** 1. pass / will deploy · 2. approves / will start · 3. doesn't respond / will check · 4. don't send / won't finish · 5. is / will add · 6. see / send · 7. fail / don't deploy · 8. share / investigate.

**B.** 1. If the tests pass, we will deploy. · 2. I'll review it tonight if you send it today. · 3. Unless you approve the design, we won't start. · 4. Will you roll back if it fails? · 5. What will you do if it fails? · 6. Yes, I will.

**C.** 1. If the API **fails**, I'll retry. · 2. If he **agrees**, we'll start. · 3. If it doesn't **work**, call me. · 4. We will **deploy** if it passes. · 5. **What will you do** if it fails? · 6. ...**I'll check** it tonight.

</details>

# PHẦN 2 — SO SÁNH VỚI QUY LUẬT CHUNG

## 2.1 Bảng so sánh

Câu điều kiện loại 0 (zero conditional) mô tả quy luật hoặc quy trình; đây là cách mở rộng những câu hiện tại đơn đã gặp trong Bài 01.

| Tiêu chí | Loại 0 | Loại 1 |
|---|---|---|
| Bản chất | Điều thường đúng | Tình huống tương lai có thể xảy ra |
| (+) | If + hiện tại đơn, hiện tại đơn | If + hiện tại đơn, will V |
| (−) | don't/doesn't trong vế cần phủ định | don't/doesn't trong if; won't ở kết quả |
| (?) | What happens if...? | What will happen if...? |
| Cách dùng | Mô tả hệ thống | Kế hoạch cho lần cụ thể |
| Dấu hiệu ngữ cảnh | always, every time | tonight, lần deploy sắp tới |
| Đặc biệt | If có thể gần nghĩa when trong quy trình | Kết quả có thể dùng can/should/mệnh lệnh |

## 2.2 Cặp câu đối chiếu

| Loại 0 | Loại 1 | Khác nhau ở đâu |
|---|---|---|
| If a test fails, the pipeline stops. | If a test fails tonight, we'll stop the release. | Cấu hình chung ↔ quyết định lần tới |
| If a payment fails, the app sends an email. | If this payment fails, I'll send you an email. | Tự động thường lệ ↔ hành động cụ thể |
| If users forget their password, they reset it. | If you forget your password, I'll help you reset it. | Quy trình ↔ hỗ trợ một tình huống |

## 2.3 Mẹo chọn nhanh

1. Đang giải thích hệ thống luôn làm gì? → hiện tại đơn ở hai vế.
2. Đang nói lần sắp tới và cách xử lý? → loại 1.
3. Muốn chỉ dẫn người nghe? → vế kết quả có thể dùng mệnh lệnh.

> *The pipeline stops if a test fails. If the tests pass tonight, we'll deploy the patch. If an error appears after deployment, I'll check the logs. If you see a payment issue, send me a screenshot.*

## 2.4 Bài tập tổng hợp

### A. Chọn theo ngữ cảnh

1. Quy trình tự động: If a payment fails, the app (sends / will sending) an email.
2. Kế hoạch tối nay: If tests pass, we (will deploy / deployed).
3. If she (approves / will approve) tomorrow, we'll start.
4. If it (doesn't work / doesn't works), call me.
5. If you send logs, I can (investigate / investigated).
6. We won't start (unless / if) you approve. Nghĩa: chỉ bắt đầu sau khi được duyệt.
7. (Will / Do) you roll back if the release fails tonight?
8. If you see the error, (send / sends) a screenshot.
9. I've already (tested / test) the patch. (Ôn Bài 04)
10. Could you tell me when (you are available / are you available)? (Ôn Bài 02)

### B. Sửa lỗi

1. If you will send it, I'll check it.
2. If she agree, we can start.
3. If it fails, we will rolls back.
4. Will you deploy if the tests will pass?
5. If you don't approves, we won't start.
6. If you see an error, to send a screenshot.

### C. Viết tin nhắn

Viết 5–6 câu cho client: điều kiện nhận logs để điều tra, điều kiện duyệt thiết kế để bắt đầu, phương án nếu deploy lỗi và một câu hướng dẫn gửi screenshot. Thêm một câu hiện tại đơn mô tả quy trình của hệ thống đặt vé.

<details>
<summary>Đáp án và gợi ý Phần 2</summary>

**A.** 1. sends · 2. will deploy · 3. approves · 4. doesn't work · 5. investigate · 6. unless · 7. Will · 8. send · 9. tested · 10. you are available.

**B.** 1. If you **send** it... · 2. If she **agrees**... · 3. ...we will **roll back**. · 4. ...if the tests **pass**? · 5. If you don't **approve**... · 6. ...**send** a screenshot.

**C. Mẫu:** If you share the logs, I can investigate the issue. If you approve the design, I'll start the checkout page. If deployment fails, we'll roll back. If a payment fails, the app shows an error message. If you see that message, send me a screenshot.

</details>
