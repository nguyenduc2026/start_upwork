# PHẦN 1 — THÌ HIỆN TẠI HOÀN THÀNH (Present Perfect)

## 1.1 Khái niệm

Hiện tại hoàn thành nhìn một việc trước hiện tại từ góc nhìn **bây giờ**: kết quả đang liên quan, kinh nghiệm tính đến nay hoặc trạng thái kéo dài đến nay. Không dùng thì này để kể một sự kiện gắn trực tiếp với thời gian quá khứ đã kết thúc như *yesterday*.

> *I've fixed the login bug.* → Tôi thông báo kết quả hiện có: lỗi đã được sửa. Người nghe quan tâm kết quả bây giờ hơn giờ sửa chính xác.

## 1.2 Công thức

**V3** = quá khứ phân từ (past participle), không phải lúc nào cũng giống V2.

| Chủ ngữ | (+) | (−) | (?) |
|---|---|---|---|
| I / you / we / they / số nhiều | S + **have + V3** | S + **have not + V3** | **Have + S + V3**? |
| He / she / it / số ít | S + **has + V3** | S + **has not + V3** | **Has + S + V3**? |

- Viết tắt: *I've, you've, we've, they've, he's, she's, it's; haven't, hasn't*.
- *He's fixed it* = *He has fixed it*; *He's busy* = *He is busy*. Nhìn phần sau để hiểu *'s*.
- *Have you tested it? — Yes, I have. / No, I haven't.*
- *Has she replied? — Yes, she has. / No, she hasn't.* Không trả lời *Yes, she's*.
- Wh-: *What have you changed?* / *How long has the server been down?*
- Hỏi chủ ngữ: *Who has changed the password?* — *has* vẫn cần vì nó là một phần của thì.
- Với *be*: *The server has been slow.* / *It hasn't been stable.* / *Has it been slow?* Không dùng *has was*.

## 1.3 V3 và phát âm

Động từ có quy tắc: V3 = V2, cùng quy tắc -ed và cách đọc /t/, /d/, /ɪd/ ở [Bài 03](03-past-simple.md#13-quy-tắc-biến-đổi-và-phát-âm). Ví dụ *fixed* /t/, *deployed* /d/, *updated* /ɪd/. Không thêm -s hay -ing vào V3.

| V | V2 | V3 |
|---|---|---|
| be | was/were | been |
| do | did | done |
| go | went | gone |
| write | wrote | written |
| see | saw | seen |
| take | took | taken |
| give | gave | given |
| know | knew | known |
| run | ran | run |
| begin | began | begun |
| send | sent | sent |
| build | built | built |
| find | found | found |
| make | made | made |
| have | had | had |
| read | read | read |
| pay | paid | paid |
| get | got | got (Anh–Anh) / gotten (nhiều cách dùng Anh–Mỹ) |

*Read* ở V2/V3 đọc /red/. *Been* có các biến thể phát âm /biːn/, /bɪn/ tùy giọng và ngữ cảnh. Học cả cụm: *has been*, *have written*, thay vì chỉ học V3 rời.

## 1.4 Cách dùng

**① Kết quả liên quan hiện tại:** *I've fixed the bug; please test it.* / *The client has approved the design, so we can start.*

**② Kinh nghiệm tính đến nay, không nêu thời gian quá khứ cụ thể:** *I've worked with Stripe before.* / *Have you ever built a booking system?*

**③ Trạng thái hoặc hoạt động kéo dài đến hiện tại:** *I've known this client for two years.* / *She has worked here since 2023.* Với *work/live*, dạng đơn này dùng được; hiện tại hoàn thành tiếp diễn là một chủ điểm khác, chưa cần học trong bài.

**④ Việc tính đến lúc này trong khoảng thời gian còn mở:** *I've fixed three bugs today.* / *We've had two calls this week.* Người nói xem hôm nay/tuần này là giai đoạn còn tiếp tục.

## 1.5 Dấu hiệu và vị trí

| Từ/cụm | Vị trí thường dùng | Ví dụ |
|---|---|---|
| just — vừa mới | have/has + just + V3 | I've just sent it. |
| already — đã rồi | Thường trước V3; cũng có thể cuối câu | She has already replied. |
| yet — chưa | Thường cuối câu hỏi/phủ định | Have you tested it yet? / Not yet. |
| ever / never | Trước V3 | Have you ever used Redis? / I've never used it. |
| so far — tính đến nay | Đầu/cuối câu | We've fixed five bugs so far. |
| since + mốc bắt đầu | Cuối câu | The server has been down since 9 AM. |
| for + khoảng thời gian | Cuối câu | It has been down for two hours. |

*Since Monday, since 2023, since I joined the team*; *for an hour, for three years*. *For* không tự quyết định thì: *I worked there for a year in 2020* là một khoảng đã kết thúc.

## 1.6 Lưu ý và ngoại lệ

- Không kết hợp *have fixed yesterday*: khi nêu *yesterday*, dùng *fixed*.
- *I've never used it*, không dùng *haven't never* trong tiếng Anh chuẩn.
- *Been to* = đã từng đến và quay lại: *She's been to London.* *Gone to* = đã đi và hiện chưa về: *She's gone to the office.*
- *I've lost the key* thường ngụ ý hiện chưa có chìa; nếu đã tìm lại và kể chuyện hôm qua, dùng *I lost it yesterday, but I found it later*.
- Anh–Mỹ có thể dùng quá khứ đơn với *just/already/yet* trong nhiều ngữ cảnh: *I just sent it.* Bài tập có yêu cầu hiện tại hoàn thành thì luyện theo yêu cầu; khi chấm tin nhắn tự do, chấp nhận cách dùng đúng theo biến thể.

## 1.7 Ví dụ

| Câu | Cách dùng |
|---|---|
| I've pushed the patch. | ① báo kết quả |
| The tests have passed. | ① có kết quả |
| I've built two booking systems. | ② kinh nghiệm |
| Has she ever used Laravel? | ② hỏi kinh nghiệm |
| We've worked together for three years. | ③ đến hiện tại |
| The server has been down since noon. | ③ trạng thái còn tiếp tục |
| I've sent two updates today. | ④ đếm đến lúc này |
| We haven't received any feedback yet. | ① chưa nhận được tính đến nay |

## 1.8 Lỗi thường gặp

| ❌ | ✅ | Lý do |
|---|---|---|
| She have replied. | She has replied. | She → has |
| I've wrote the tests. | I've written the tests. | Cần V3 |
| I've sent it yesterday. | I sent it yesterday. | Mốc quá khứ đã kết thúc |
| I've known her since two years. | I've known her for two years. | Khoảng thời gian → for |
| Have you ever use Redis? | Have you ever used Redis? | Have + V3 |
| I haven't never used it. | I've never used it. | Tránh phủ định kép |

## 1.9 Bài tập Phần 1

### A. Viết V3

1. write
2. send
3. run
4. be
5. do
6. build
7. see
8. take

### B. Điền theo hiện tại hoàn thành; câu 7–8 điền since/for

1. I ___ (just / push) the patch.
2. She ___ (not / reply) yet.
3. ___ you ever ___ (use) Stripe?
4. The server ___ (be) down since noon.
5. We ___ (fix) three bugs so far.
6. What ___ you ___ (change)?
7. I've known him ___ 2022.
8. We've worked together ___ four years.

### C. Sửa lỗi

1. He have finished the tests.
2. I have wrote the report.
3. We have been here since two hours.
4. Has she saw the update?

# PHẦN 2 — SO SÁNH VỚI QUÁ KHỨ ĐƠN

## 2.1 Bảng so sánh

| Tiêu chí | Hiện tại hoàn thành | Quá khứ đơn |
|---|---|---|
| Bản chất | Nhìn từ hiện tại về trước | Đặt việc vào thời gian đã qua |
| (+) | have/has + V3 | V2 / was/were |
| (−) | haven't/hasn't + V3 | didn't + V / wasn't/weren't |
| (?) | Have/Has S V3? | Did S V? / Was/Were S ...? |
| Cách dùng | Kết quả, kinh nghiệm, kéo dài đến nay | Sự kiện, chuỗi việc, giai đoạn đã kết thúc |
| Dấu hiệu thường gặp | so far, since, yet | yesterday, ago, last week |
| Điểm cần thận trọng | today/this week tùy góc nhìn | Không cần nêu giờ nếu ngữ cảnh đã rõ |

## 2.2 Cặp câu đối chiếu

| Câu 1 | Câu 2 | Khác nhau ở đâu |
|---|---|---|
| I've fixed the bug. | I fixed the bug yesterday. | Kết quả hiện tại ↔ sự kiện hôm qua |
| I've worked here for two years. | I worked there for two years. | Còn làm ở đây ↔ thời gian làm ở đó đã kết thúc |
| Have you used Stripe before? | Did you use Stripe on that project? | Kinh nghiệm đến nay ↔ project cụ thể đã qua |
| I've sent two updates today. | I sent two updates yesterday. | Khoảng còn mở ↔ khoảng đã đóng |

## 2.3 Mẹo chọn nhanh

1. Có thời gian đã kết thúc gắn trực tiếp với hành động? → quá khứ đơn.
2. Kinh nghiệm đến nay, kết quả bây giờ, trạng thái còn tiếp tục? → cân nhắc hiện tại hoàn thành.
3. Đang kể chi tiết “lúc nào, chuyện gì tiếp theo”? → thường chuyển sang quá khứ đơn.

> *Hi Sam, I've fixed the checkout bug. I found the cause yesterday and updated the validation this morning. I've also added two tests. I haven't deployed the patch yet. Could you review it?*

## 2.4 Bài tập tổng hợp

### A. Chọn theo ý nghĩa được cho

1. I (have sent / sent) the report yesterday.
2. She (has never used / never used) Redis in her career so far.
3. We (have met / met) the client last Friday.
4. The server (has been / was) down since 9 AM; it is still down.
5. I (have worked / worked) there in 2020.
6. We (have fixed / fixed) five bugs so far today.
7. (Have / Did) you ever built a booking system?
8. When (have you sent / did you send) the file yesterday?
9. I (didn't receive / haven't received) any feedback yet. Use Present Perfect.
10. She (has known / knew) this client for years, and they still work together.

### B. Sửa lỗi

1. I have fixed it last night.
2. Did you ever built a booking system?
3. She has work here since 2023.
4. We haven't receive the file yet.
5. The server has been down since three hours.
6. Could you tell me what have you changed?

### C. Viết tin nhắn

Viết 5–7 câu: báo hai kết quả tính đến nay, một việc chưa làm, một việc đã làm hôm qua và một câu hỏi xin phản hồi. Dùng ít nhất một *already/yet* và một mốc quá khứ rõ ràng.

<details>
<summary>Đáp án và gợi ý Phần 2</summary>

**A.** 1. sent · 2. has never used · 3. met · 4. has been · 5. worked · 6. have fixed · 7. Have · 8. did you send · 9. haven't received · 10. has known.

**B.** 1. I **fixed** it last night. · 2. **Have** you ever **built** a booking system? (hoặc *Did you ever build...?* trong ngữ cảnh quá khứ phù hợp) · 3. She has **worked** here since 2023. · 4. We haven't **received** the file yet. · 5. ...down **for** three hours. · 6. Could you tell me what **you have changed**?

**C. Mẫu:** Hi Sam, I've fixed the login bug. I've already added the tests. I checked the checkout logs yesterday. I haven't deployed the patch yet. Could you let me know if the changes look good?

</details>
